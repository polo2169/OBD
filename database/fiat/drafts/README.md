# Profils Fiat non publiés

Ce dossier conserve les variantes historiques ou incomplètes. Les fichiers qui
s'y trouvent ne sont pas chargés par `KnowledgeBase` et ne doivent pas apparaître
dans le sélecteur de véhicule.

Pour publier un profil, fusionner les informations utiles dans le profil
canonique sous `database/fiat/vehicles/`, valider ses sources puis exécuter les
contrôles du projet.
